4. THE PHASE 1b TEST: DO SAHIH + DA'IF ADD UP TO THE TOTAL?
----------------------------------------------------------------------
Hadith in F: 1896.   Albani entries with any label: 86  (+8 unlabeled comments).
Sahih (22) + da'if (54) = 76; with hasan/shadh/mixed: 86.
=> They do not add up to 1896 (they cover 4.5%). Under the rule you set, this is 'problematic'.

WHY: Albani's edition is a lightly annotated text. He footnotes the hadith he wants to correct or qualify and says nothing about the rest.
His silence is not a grade in this file: the ~1800 unmarked hadith are not labelled sahih in any entry.

5. CONSEQUENCE FOR PHASE 2 (what has to be decided)
----------------------------------------------------------------------
To say which Riyad hadith are 'sahih according to Albani' we need a grade for every hadith. The only Albani-grade evidence inside the supplied files is:
  (1) this file (94 hadith, mostly da'if),
  (2) Mishkat al-Masabih (Albani's edition): footnote grades for every hadith that Mishkat contains and that is not in Bukhari/Muslim,
  (3) Nawawi's own attribution in Riyad: 'muttafaq 'alayh' / 'rawahu al-Bukhari' / 'rawahu Muslim' (the Sahihayn, which Albani treats as sahih).
An 'evidence ladder' built from these gives a defensible sahih / da'if / not-graded split without guessing. See the Phase 2 notes in Notion.
